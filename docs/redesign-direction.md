## Direction: a living layout

Warm porcelain and ink provide the editorial foundation. Cobalt identifies actions and the interactive lab; acid lime is a sparing annotation color. Oversized name typography anchors an asymmetric hero. A code-drawn composition board reflects alignment, layers, and responsive systems. It is explicitly a portfolio demo, not project work.

Learnify receives a yellow, image-led screen explorer using the three existing original exports. CRM receives a compact, typographic prototype folio with direct source access and an explicit export-status note. The lab lets visitors change appearance, density, variant, selection, and preview width using native controls. About/skills uses a marginal-note and editorial-list composition. Case-study pages share the same new typographic system and interactive screen explorer.

CSS perspective and small React islands provide the spatial interaction without Three.js. This keeps the essential content server-rendered, avoids GPU dependence, and adds no dependencies. Motion consists of a short entrance, restrained pointer tilt, state transitions, and optional on-view reveals; reduced-motion disables nonessential motion. Content stays visible before hydration and without JavaScript.
